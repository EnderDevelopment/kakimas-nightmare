# Kakima's Nightmare

Kakima's Nightmare is a Minecraft plugin that introduces a custom female NPC named "Kakima" into your server. This plugin features smooth, realistic animations for walking, running, and eating. Kakima roams villages, enters houses at night, steals and eats potatoes from farms, chops trees, and sometimes builds her own small wooden house. When a player approaches her, she says "আমি তো কিছুই করিনি 😚". If she is attacked, she runs away in panic and alerts nearby Iron Golems to chase and attack the player. The plugin also includes creepy ambient sounds, funny reactions, and unpredictable AI behavior.

## Install

1. Download the latest release from the [GitHub repository](https://github.com/EnderDevelopment/KakimaPlugin).
2. Place the downloaded JAR file into the `plugins` folder of your Minecraft server.
3. Restart your server.

## Use

1. Join the server and use the command `/kakima` to spawn Kakima.
2. Observe Kakima's behavior as she roams the village, interacts with players, and engages in her unique activities.
